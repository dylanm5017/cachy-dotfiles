# Quickshell Config

This is the default Quickshell config for the Hyprland session.

## Run

```sh
qs
```

For a one-instance launch:

```sh
qs -n
```

## Hyprland Startup

Add this to the Hyprland config when wiring the shell into session startup:

```ini
exec-once = qs -n
```

## Structure

- `shell.qml` is the stable root entrypoint loaded by `qs`.
- `modules/bar/` owns the visible bar surface and widgets.
- `modules/common/` owns reusable visual primitives for compact shell controls.
- `modules/island/` owns the centered live island used by the bar.
- `modules/dock/` owns the focused-monitor smart dock.
- `modules/overlays/` owns transient surfaces like audio OSD and notifications.
- `services/` owns reusable shell state, including native audio, media, notification, command, and clipboard state.
- `services/QuietState.qml` is an inactive placeholder for future quiet-mode work.
- `SmokyPlumTheme.qml` is generated by the Design System and should not be edited by hand.

All UI colors should come from `SmokyPlumTheme.qml`; keep hardcoded colors out of QML components except for Quickshell window transparency.

## Development Conventions

- Put cross-surface state in `services/` and register shared services in `services/qmldir`.
- Put reusable visual building blocks in `modules/common/`.
- Keep bar-only widgets in `modules/bar/` and transient surfaces in `modules/overlays/`.
- Keep larger shell identity pieces, like the island and dock, in their own focused modules.
- Prefer compact shell surfaces, stable dimensions, and short motion over decorative effects.
- Keep generated theme changes in the Design System; do not edit `SmokyPlumTheme.qml` by hand.

- Focused window chip powered by Hyprland IPC.
- MPRIS media capsule with click-to-toggle playback.
- PipeWire-backed volume status and OSD.
- System tray cluster.
- Notification toast stack on the focused monitor.
- Command drawer with quick actions, favorite app launchers, and clipboard history.
- Centered live island for clock, media, audio, command, and notification states.
- Focused-monitor smart dock for favorite apps and quick actions.
- Centered command drop-down, refined toast hierarchy, and a compact volume HUD.
